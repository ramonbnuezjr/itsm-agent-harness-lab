# VPN Access Troubleshooting

Use this procedure when a user cannot establish the corporate VPN connection.

1. Confirm the user has internet access without the VPN.
2. Verify the VPN client reports the expected gateway and does not show an expired certificate.
3. Ask the user to retry after correcting the device clock and restarting the VPN client.
4. If multi-factor authentication fails, follow the MFA recovery procedure; do not bypass MFA.
5. Escalate to the network team when multiple users are affected or the gateway is unreachable.

Record the client error code, gateway, device OS, and troubleshooting already attempted. Never request or log the user's password or MFA code.
